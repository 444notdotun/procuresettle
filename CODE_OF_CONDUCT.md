# Code of Conduct

ProcureSettle adopts the [Contributor Covenant Code of Conduct, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Contributors and reviewers are expected to follow its community standards in
project spaces, including issues, pull requests, and discussions.

## Reporting

For a community moderation concern, contact the project maintainer through
their [GitHub profile](https://github.com/starboytiimz). Please do not post
personal or sensitive details in a public issue. Reports will be reviewed
respectfully and handled as confidentially as the available communication
channel permits.
